# Clef-flash

Clef-flash by Cloudflare - an open (Apache-2.0) System One decision model built on Qwen that answers typed questions about a state with calibrated probabilities; the most accurate hosted choice for many-option intent sets, served through the OpenRouter API.

This definition was generated by the [Model Definition Builder](../../Model-Definition-Builder/README.md) from `definition.yaml` — edit that file and run `mdb generate clef_flash` instead of editing the generated files by hand.

- The key arrives per call in the `API_KEY` option; the container posts the state and the questions to the provider's System One endpoint and needs no environment configuration beyond network access to it.
