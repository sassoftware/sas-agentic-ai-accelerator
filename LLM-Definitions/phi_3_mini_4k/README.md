# Phi 3 Mini 4k

This definition was generated by the [Model Definition Builder](../../Model-Definition-Builder/README.md) from `definition.yaml` — edit that file and run `mdb generate phi_3_mini_4k` instead of editing the generated files by hand.

## Deployment

What the SCR container needs from its environment (the caller-side options are in the table above):

- The weights are read from the shared `llm-weights` volume at `/pybox/model/mount/phi_3_mini_4k` - stage them there once; the image itself carries no weights. Use the persistent-volume deployment YAML.

## Register and publish

```bash
mdb register phi_3_mini_4k
mdb publish phi_3_mini_4k -d <your-destination>
```

Or do both in one step with `mdb ship phi_3_mini_4k`. The publishing destination can also come from `SAS_PUBLISH_DESTINATION` in your `.env`.
