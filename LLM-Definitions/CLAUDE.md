# LLM Definition Builder

## Overview

Build an interactive Python CLI — `build-llm.py` — that scaffolds a new model definition folder inside `LLM-Definitions/`. Running it walks the user through provider and model details, then writes every required file so the model is immediately ready to register in SAS Model Manager.

## Context: What a Model Definition Is

Each subfolder in `LLM-Definitions/` represents one LLM registered in SAS Model Manager. The folder contains:

| File | Purpose |
|---|---|
| `modelConfiguration.json` | Model metadata (name, tags, description, responsible-AI fields) |
| `{ScoreName}Score.py` | Inference entry point — implements `scoreModel(userPrompt, systemPrompt, options)` |
| `inputVar.json` | Input schema — always identical across all models |
| `outputVar.json` | Output schema — always identical across all models |
| `options.json` | Parameter definitions (temperature, API key, provider-specific settings) |
| `requirements.json` | Two-step pip install instructions |
| `README.md` | Deployment and configuration instructions |

`_Base_Definition/` contains the canonical templates. Copy `inputVar.json` and `outputVar.json` verbatim. Use the others as structural references only — do not copy them blindly.

## Naming Conventions

### Folder name
Always lowercase, words separated by underscores. Follow the pattern of existing folders:

| Provider | Pattern | Example |
|---|---|---|
| Azure OpenAI | `{model}_az_{YYYY}_{MM}_{DD}` | `gpt_54_mini_az_2025_09_01` |
| OpenAI | `{model}_{YYYY}_{MM}_{DD}` | `gpt_54_mini_2025_09_01` |
| Anthropic | `{model}` | `claude_sonnet_4` |
| Google | `{model}` | `gemini_flash_3` |
| Meta / local | `{model}` | `llama_4_8b` |

Derive `{model}` by lowercasing the version string and replacing `.`, `-`, spaces with `_`. Drop punctuation.

Auto-suggest the folder name during the interactive flow; let the user override it.

### Score file name
Convert the folder name to camelCase (drop underscores, capitalise each segment), append `Score.py`.

Examples:
- `gpt_54_mini_az_2025_09_01` → `gpt54MiniAz20250901Score.py`
- `claude_sonnet_4` → `claudeSonnet4Score.py`

### `modelConfiguration.json`

The long `modelPurpose`, `intendedUse`, `expectedBenefit`, `outOfScopeUseCases`, `limitations` fields are fixed boilerplate — copy them from `_Base_Definition/modelConfiguration.json` unchanged. Only the following fields are derived from user input:

| Field | Source |
|---|---|
| `name` | folder name |
| `scoreCodeFile` | score file name |
| `description` | user input |
| `modeler` | user input |
| `tags` | assembled from: model size (`LLM`/`SLM`), license (`Proprietary`/`Open-Source`), provider tags, size tag (`small`/`medium`/`large`) |

**Tag sets by provider:**

| Provider | Fixed tags |
|---|---|
| Azure OpenAI | `["Proprietary", "Azure OpenAI", "Azure AI Foundry"]` |
| OpenAI | `["Proprietary", "OpenAI"]` |
| Anthropic | `["Proprietary", "Anthropic"]` |
| Google | `["Proprietary", "Google"]` |
| Meta (local) | `["Open-Source", "Meta"]` |

Full `tags` array = fixed provider tags + `[llm_or_slm, size_tag]`.

`toolVersion` is always `"3.11.9"`, `targetVariable` always `"response"`, `champion` always `false`.

### `{Name}Score.py`

Every score file follows the same structure:
1. Imports and module-level setup (tokenizer, logger)
2. `scoreModel(userPrompt, systemPrompt, options)` function
3. Options parsing via the `_parse_options` helper (handles both pandas Series from SAS and plain lists)
4. API call with error handling
5. Token counting, timing, logging
6. Commented-out `__main__` block with a working usage example

Use the full `_parse_options` helper from `gpt_41_az_2025_01_01/gpt41MiniScore.py` (lines 37-76) in every score file — it is robust and already handles all edge cases.

#### Azure OpenAI Score template

Substitute `{MODEL_VERSION}` with the API model ID (e.g. `gpt-5.4-mini`) and `{SCORE_FILE}` with the score file name.

```python
import time
import json
import logging
import sys
import requests
import tiktoken

modelVersion = '{MODEL_VERSION}'
try:
    tokenizer = tiktoken.encoding_for_model(modelVersion)
except Exception:
    tokenizer = tiktoken.get_encoding("o200k_base")

logging.basicConfig(level=logging.INFO, handlers=[logging.StreamHandler(sys.stdout)], format='%(levelname)s - %(message)s')
logger = logging.getLogger("scoreModel")

def scoreModel(userPrompt, systemPrompt, options):
    "Output: response, run_time, prompt_length, output_length"
    started_timestamp = time.time()

    optionsDefaults = {
        "temperature": 1,
        "top_p": 1,
        "azure_openai_resource": "westus3.api.cognitive.microsoft.com",
        "api_version": "2025-01-01-preview",
        "endpoint_url": None,
        "API_KEY": None
    }

    def _parse_options(opts):
        if opts is None or (hasattr(opts, '__len__') and len(opts) == 0):
            return {}
        raw = opts.iloc[0] if hasattr(opts, 'iloc') else (opts[0] if len(opts) > 0 else None)
        if not raw:
            return {}
        if isinstance(raw, dict):
            return raw
        if isinstance(raw, str):
            try:
                return json.loads(raw)
            except Exception:
                pass
            parsed = {}
            s = raw.strip()
            if s.startswith('{') and s.endswith('}'):
                s = s[1:-1]
            for piece in [p for p in s.split(',') if p.strip()]:
                if ':' not in piece:
                    continue
                k, v = piece.split(':', 1)
                k, v = k.strip().strip('"\''), v.strip().strip('"\'')
                if v.lower() in ("true", "false"):
                    parsed[k] = v.lower() == "true"
                else:
                    try:
                        parsed[k] = float(v) if '.' in v else int(v)
                    except Exception:
                        parsed[k] = v
            return parsed
        return {}

    options = {**optionsDefaults, **_parse_options(options)}

    if options.get('endpoint_url'):
        modelEndpoint = options['endpoint_url']
    else:
        host = (options.get('azure_openai_resource') or '').strip()
        if host and '.' not in host:
            host = f"{host}.openai.azure.com"
        modelEndpoint = f'https://{host}/openai/deployments/{modelVersion}/chat/completions?api-version={options["api_version"]}'

    logger.info(f"Using endpoint: {modelEndpoint}")

    headers = {"Content-Type": "application/json", "api-key": options.get('API_KEY') or ""}
    payload = {
        "messages": [
            {"role": "system", "content": systemPrompt[0]},
            {"role": "user",   "content": userPrompt[0]}
        ],
        "temperature": float(options["temperature"]),
        "top_p":       float(options["top_p"]),
    }

    responseObject = requests.post(modelEndpoint, headers=headers, json=payload, timeout=60)
    try:
        responseJson = responseObject.json()
    except Exception:
        logger.error(f"Non-JSON response: {responseObject.status_code} - {responseObject.text}")
        raise

    if not (200 <= responseObject.status_code < 300):
        logger.error(f"HTTP {responseObject.status_code}: {json.dumps(responseJson)}")
        raise RuntimeError(f"Request failed: {responseObject.status_code}")

    response = responseJson['choices'][0]['message']['content']
    prompt_length = len(tokenizer.encode(systemPrompt[0] + userPrompt[0]))
    output_length = len(tokenizer.encode(response))
    run_time = time.time() - started_timestamp

    logger.info(f"prompt_length: {prompt_length}")
    logger.info(f"output_length: {output_length}")
    logger.info(f"run_time: {run_time}")
    logger.info(f"response: {response}")
    return response, run_time, prompt_length, output_length


# Example usage — uncomment, replace API_KEY, and run: python {SCORE_FILE}
"""

    systemPrompt = ["You are an AI Assistant helping people learn languages"]
    options = ["{azure_openai_resource:westus3.api.cognitive.microsoft.com,api_version:2025-01-01-preview,temperature:1,top_p:1,API_KEY:***your_actual_API_key_here***}"]
    response, run_time, prompt_length, output_length = scoreModel(userPrompt, systemPrompt, options)
    print("Response:", response)
    print("Run time:", run_time)
"""
```

#### OpenAI Score template

Same structure. Key differences:
- Endpoint: `https://api.openai.com/v1/chat/completions`
- Auth header: `"Authorization": f"Bearer {options['API_KEY']}"`
- No `azure_openai_resource`, `api_version`, or `endpoint_url` in optionsDefaults

#### Anthropic Score template

Key differences from Azure:
- Endpoint: `https://api.anthropic.com/v1/messages`
- Headers: `"x-api-key"`, `"anthropic-version": "2023-06-01"`, `"content-type": "application/json"`
- Payload structure: `{"model": modelVersion, "max_tokens": int(options["max_tokens"]), "system": systemPrompt[0], "messages": [{"role": "user", "content": userPrompt[0]}]}`
- Response extraction: `responseJson['content'][0]['text']`
- `max_tokens` is required in the request

#### Google (Gemini) Score template

Key differences:
- Endpoint: `https://generativelanguage.googleapis.com/v1beta/models/{modelVersion}:generateContent?key={API_KEY}`
- No `Authorization` header — key goes in the URL
- Payload: `{"contents": [{"parts": [{"text": systemPrompt[0] + "\n" + userPrompt[0]}]}], "generationConfig": {"temperature": ..., "topP": ..., "maxOutputTokens": ...}}`
- Response extraction: `responseJson['candidates'][0]['content']['parts'][0]['text']`

### `README.md`

Generate a provider-appropriate README. Use `gpt_41_az_2025_01_01/README.md` as the gold-standard template for Azure OpenAI.

Every README must include:
1. H1 heading: model display name + provider
2. **Required Items** section — what the user must set up before using the model
3. **Create a Model Deployment** section (if applicable) — step-by-step for the specific provider's portal
4. **Retrieve your API Key and Endpoint** section
5. **Configuration Options** section — table of all fields from `options.json` with defaults and examples
6. **Example Options Strings** — copy-pasteable options strings for the SAS scoring call
7. **Testing Locally** — show the `__main__` block with realistic placeholder values and the run command

## Validation Rules

- Folder must not already exist in `LLM-Definitions/`. If it does, abort with a clear error.
- Model version / API ID is required (non-empty).
- Score file name must end in `Score.py`.
- Folder name must be lowercase, underscores only (no spaces, no hyphens, no uppercase).

---

## Implementation Notes

- The builder lives at `LLM-Definitions/build-llm.py`. Run with `python build-llm.py` from the `LLM-Definitions/` directory.
- No external dependencies beyond the Python standard library. Use only `os`, `json`, `re`, `datetime`, `textwrap`, and `input()`.
- The `_Base_Definition/` folder is the source of truth for `inputVar.json` and `outputVar.json`. Read and re-write them rather than hardcoding to stay in sync.
- After writing all files, print a summary of what was created and remind the user to run `register-LLMs.py`.
