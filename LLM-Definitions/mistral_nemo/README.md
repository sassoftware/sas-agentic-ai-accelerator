# Mistral Nemo

The Mistral-Nemo-Instruct-2407 Large Language Model (LLM) is an instruct fine-tuned version of the Mistral-Nemo-Base-2407. Trained jointly by Mistral AI and NVIDIA, it significantly outperforms existing models smaller or similar in size.

This definition was generated by the [Model Definition Builder](../../Model-Definition-Builder/README.md) from `definition.yaml` — edit that file and run `mdb generate mistral_nemo` instead of editing the generated files by hand.

## Configuration options

The following options can be supplied at scoring time through the `options` input (see the [LLM-Definitions README](../README.md) for the format):

| Option | Default | Range | Description |
| ------ | ------- | ----- | ----------- |
| `temperature` | 0.3 | 0 - 2 | What sampling temperature to use, between 0 and 2. Higher values like 0.8 will make the output more random, while lower values like 0.2 will make it more focused and deterministic. |
| `max_tokens` | 256 | 1 - 128000 (minus input token length) | Limits the amount of output tokens generated by the model. |

## Deployment

What the SCR container needs from its environment (the caller-side options are in the table above):

- The key arrives per call in the `API_KEY` option; the container needs no environment configuration beyond network access to the provider.

## Register and publish

```bash
mdb register mistral_nemo
mdb publish mistral_nemo -d <your-destination>
```

Or do both in one step with `mdb ship mistral_nemo`. The publishing destination can also come from `SAS_PUBLISH_DESTINATION` in your `.env`.
