# Voyage 3.5

Voyage.ai introduces voyage-3.5, the latest generation of their embedding models. This model offers improved retrieval quality over voyage-3 at the same price, setting a new frontier for price-performance.

This definition was generated by the [Model Definition Builder](../../Model-Definition-Builder/README.md) from `definition.yaml` — edit that file and run `mdb generate voyage_35` instead of editing the generated files by hand.
