# Granite Embedding English R2

IBM Granite Embedding English R2: a 149M-parameter ModernBERT dense bi-encoder producing 768-dimensional vectors over an 8192-token context, tuned for enterprise retrieval. Apache-2.0.

This definition was generated by the [Model Definition Builder](../../Model-Definition-Builder/README.md) from `definition.yaml` — edit that file and run `mdb generate granite_embedding_r2` instead of editing the generated files by hand.

## Configuration options

The following options can be supplied at scoring time through the `options` input (see the [LLM-Definitions README](../README.md) for the format):

| Option | Default | Range | Description |
| ------ | ------- | ----- | ----------- |
| `Embedding_Mode` | query | query | document | Whether the text is embedded as a query (for retrieval) or as a document (for storage/indexing). Using the matching mode on both sides improves retrieval quality. |
| `Embedding_Length` | 768 | 768 | The length of the returned embedding vector. |
| `Input_Token_Limit` | 8192 | 8192 | The limit of input tokens for the embedding model. |
