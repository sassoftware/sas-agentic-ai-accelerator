# Text Embedding 3 Large

text-embedding-3-large is OpenAIs most capable embedding model for both english and non-english tasks. Embeddings are a numerical representation of text that can be used to measure the relatedness between two pieces of text. Embeddings are useful for search, clustering, recommendations, anomaly detection, and classification tasks.

This definition was generated by the [Model Definition Builder](../../Model-Definition-Builder/README.md) from `definition.yaml` — edit that file and run `mdb generate text_embedding_3_large` instead of editing the generated files by hand.

## Configuration options

The following options can be supplied at scoring time through the `options` input (see the [LLM-Definitions README](../README.md) for the format):

| Option | Default | Range | Description |
| ------ | ------- | ----- | ----------- |
| `Embedding_Length` | 3072 | 3072 | The length of the returned embedding vector. |
| `Input_Token_Limit` | 8192 | 8192 | The limit of input tokens for the embedding model. |
| `API_KEY` | OpenAI | sk-**** | This is the OpenAI key that is used to make the actual request. |
