# All MiniLM L6 v2

all-MiniLM-L6-v2 - This is a sentence-transformers model: It maps sentences & paragraphs to a 384 dimensional dense vector space and can be used for tasks like clustering or semantic search.

This definition was generated by the [Model Definition Builder](../../Model-Definition-Builder/README.md) from `definition.yaml` — edit that file and run `mdb generate all_minilm_l6_v2` instead of editing the generated files by hand.

## Configuration options

The following options can be supplied at scoring time through the `options` input (see the [LLM-Definitions README](../README.md) for the format):

| Option | Default | Range | Description |
| ------ | ------- | ----- | ----------- |
| `Embedding_Mode` | query | query | document | Whether the text is embedded as a query (for retrieval) or as a document (for storage/indexing). Using the matching mode on both sides improves retrieval quality. |
| `Embedding_Length` | 384 | 384 | The length of the returned embedding vector. |
| `Input_Token_Limit` | 256 | 256 | The limit of input tokens for the embedding model. |

## Register and publish

```bash
mdb register all_minilm_l6_v2
mdb publish all_minilm_l6_v2 -d <your-destination>
```

Or do both in one step with `mdb ship all_minilm_l6_v2`. The publishing destination can also come from `SAS_PUBLISH_DESTINATION` in your `.env`.
