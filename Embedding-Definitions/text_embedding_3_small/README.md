# Text Embedding 3 Small

text-embedding-3-small is OpenAI's improved, more performant version of their ada embedding model. Embeddings are a numerical representation of text that can be used to measure the relatedness between two pieces of text. Embeddings are useful for search, clustering, recommendations, anomaly detection, and classification tasks.

This definition was generated by the [Model Definition Builder](../../Model-Definition-Builder/README.md) from `definition.yaml` — edit that file and run `mdb generate text_embedding_3_small` instead of editing the generated files by hand.

## Register and publish
