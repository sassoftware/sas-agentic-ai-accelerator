# Text Embedding Ada 002

text-embedding-ada-002 is OpenAIs improved, more performant version of OpenAIs ada embedding model. Embeddings are a numerical representation of text that can be used to measure the relatedness between two pieces of text. Embeddings are useful for search, clustering, recommendations, anomaly detection, and classification tasks.

This definition was generated by the [Model Definition Builder](../../Model-Definition-Builder/README.md) from `definition.yaml` — edit that file and run `mdb generate text_embedding_ada_002` instead of editing the generated files by hand.
